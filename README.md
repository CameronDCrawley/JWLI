## JWLI (Japanese Women's Leadership Initiative) Website
A comprehensive web implementation for the Japanese Women's Leadership Initiative (JWLI)—empowering Japanese women to become leaders, foster social innovation, and drive community change.

## Live Demo
Netlify Deployment: https://jwlinstis.netlify.app/

## Features
Navigation Bar: Multi-page menu including Home, Program, JWLIA, Fellows, News, Contact, language switching (日本語), and an action button (Apply).

Mission & Goals Section: Highlights core initiatives aimed at developing leadership skills, empowering women in civil society, and nonprofit management training.

History & Archive: Details the origins of JWLI in Boston, Massachusetts, alongside photo gallery figures documenting board dinners and leadership discussions.

Leadership Spotlight: Profiles key founders and organizers, including Atsuko Toko Fish and partnering institutions like the Fish Family Foundation and Simmons University.

Interactive Forms: Integrated email sign-up and newsletter submission text areas.

Comprehensive Footer: Organized sitemap and social media links (YouTube, Facebook, Newsletter).

## How It Works
Structure & Layout: Built using semantic HTML5 elements (<header>, <main>, <section>, <article>, <figure>, <footer>) to maintain a clean document outline.

Styling Integration: Linked to an external stylesheet (css/style.css) for responsive styling, typography, and grid/flex layout positioning.

Interactive Components: Incorporates form inputs (<textarea> and <button>) for user engagement and newsletter signups.
